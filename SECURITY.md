# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private reporting instead:

[Security → Report a vulnerability](https://github.com/machinebreak/quasarterm/security/advisories/new)

You'll get an acknowledgment within a few days, and updates while the fix is being prepared.
Thanks for helping keep Quasar users safe.

## Supported versions

Only the latest release is supported with security fixes.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |
